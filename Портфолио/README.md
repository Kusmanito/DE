# Портфолио

Студент добавляет достижения и прикладывает сертификат или диплом в PDF или JPG. Куратор подтверждает или отклоняет запись. После подтверждения студент может оставить один отзыв.

- [Главная](index.php), [вход](login.php), [регистрация](register.php)
- [Мои достижения](dashboard.php), [новое достижение](add_request.php), [панель куратора](admin.php)
- [SQL для установки](portfolio.sql) и [материалы задания](Материалы%20задания/README.md)
- [Прототипы в draw.io](https://app.diagrams.net/#Uhttps%3A%2F%2Fraw.githubusercontent.com%2FKusmanito%2FDE%2Fmain%2F%25D0%259F%25D0%25BE%25D1%2580%25D1%2582%25D1%2584%25D0%25BE%25D0%25BB%25D0%25B8%25D0%25BE%2F%25D0%259C%25D0%25B0%25D1%2582%25D0%25B5%25D1%2580%25D0%25B8%25D0%25B0%25D0%25BB%25D1%258B%2520%25D0%25B7%25D0%25B0%25D0%25B4%25D0%25B0%25D0%25BD%25D0%25B8%25D1%258F%2F%25D0%259F%25D1%2580%25D0%25BE%25D1%2582%25D0%25BE%25D1%2582%25D0%25B8%25D0%25BF%25D1%258B%2Fprototypes.drawio) и [исходный файл диаграммы](Материалы%20задания/Прототипы/prototypes.drawio)
